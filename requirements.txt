# Top-level requirements manifest for the monorepo
# This file used to contain a large flattened list of packages (many were desktop/Jupyter/system libs).
# To keep frontend and backend concerns separated, we now split requirements:
# - backend/requirements.txt (runtime requirements for the Django backend)
# - backend/requirements-dev.txt (dev/test requirements for the backend)
# - frontend/package.json (frontend deps managed by npm/yarn/pnpm)

# To install backend runtime dependencies (recommended):
#pip install -r backend/requirements.txt

# To install backend dev/test dependencies (recommended for local dev):
#   pip install -r backend/requirements-dev.txt

# If you want to fully replicate the old environment, see the git history or ask to restore a monolithic file.
